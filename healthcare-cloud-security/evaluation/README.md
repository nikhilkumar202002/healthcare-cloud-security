## How to Run the Evaluation

### Step 1: Open Terminal in VS Code
Open your VS Code terminal (<kbd>Control</kbd> + <kbd>`</kbd>) and ensure you are in the project root directory:
```bash
cd ~/Desktop/Sreelakshmi/Project/healthcare-cloud-security
```

### Step 2: Activate Your Virtual Environment
```bash
source .venv/bin/activate
```
*(Your terminal prompt will display `(.venv)` confirming the environment is active).*

### Step 3: Run the Comparative Evaluation Program
```bash
python evaluation/compare_models.py
```

### Step 4: Run the Complete Pytest Test Suite
To verify that all unit tests across all three models continue to pass:
```bash
pytest -v
```

## Methodology Summary

- **Timing Function:** `time.perf_counter()` (monotonic high-precision clock).
- **Repetitions:** 10,000 iterations per scenario to eliminate OS noise and micro-jitter.
- **Warm-Up:** 500 initial executions prior to measurement for cache and JIT/bytecode stabilization.
- **Reporting Units:** Microseconds ($\mu\text{s}$) and milliseconds ($\text{ms}$).
- **Disclaimer:** Local Python execution timings evaluate internal algorithmic overhead and do not include cloud network round-trip latencies.
